# Desktop Cat

우리집 고양이를 데스크탑 위에서 볼 수 있게 만들기 위해 시작한 Electron 데스크탑 펫 프로젝트입니다.

고양이는 화면 위를 걷고, 쉬고, 커서를 사냥하고, 낮은 확률로 춤을 춥니다. 작업 중인 사용자의 집중 시간과 마우스 움직임에 반응하는 작은 데스크탑 동반자를 목표로 합니다.

## 핵심 인터랙션

### 쓰다듬기 반응

평소에 고양이를 클릭하거나 만지면 싫어하는 반응을 보입니다. 귀를 뒤로 젖히거나 꼬리를 치고, 반복해서 만지면 다른 곳으로 도망갑니다.

VS Code에서 작업한 집중 시간에 따라 반응이 달라집니다.

- 30분 정도 집중하면 사용자를 쳐다봅니다.
- 60분 정도 집중하면 골골거리며 쓰다듬기를 받아줍니다.
- 90분 이상 작업하면 먼저 다가와 화면을 가리거나 키보드 위에 눕는 방식으로 휴식을 유도합니다.

적당한 집중에는 애정 표현을 보여주고, 과도한 작업에는 방해 행동을 보여줍니다. 집중 시간을 보상과 휴식 신호로 함께 다루는 구조입니다.

### 커서 사냥 모드

커서가 고양이 주변에 가까이 오면 고양이가 커서를 눈이나 머리로 따라봅니다.

접근 횟수에 따라 반응이 단계적으로 바뀝니다.

- 첫 번째 접근: 커서를 쳐다봅니다.
- 두 번째 접근: 몸을 낮추며 준비 자세를 취합니다.
- 세 번째 이상 접근: 커서를 노려본 뒤 해당 위치로 점프합니다.

점프 직전에는 엉덩이를 씰룩이는 동작을 넣습니다. 커서를 놓친 뒤에는 아무 일도 없었다는 듯 행동해 고양이다운 흐름을 살립니다.

### 랜덤 춤

고양이는 낮은 확률로 2~4초 동안 춤을 춥니다. 춤이 끝나면 원래 행동으로 돌아갑니다.

사용자가 직접 실행하는 버튼은 두지 않습니다. 언제 발생할지 알 수 없는 작은 이벤트로 유지합니다.

VS Code 집중 시간이 1시간을 넘긴 직후에는 춤이 나올 확률을 조금 높일 수 있습니다. 숨겨진 축하 이벤트처럼 동작하도록 설계합니다.

## 현재 구현된 기능

- 투명한 데스크탑 고양이 창
- 걷기, 쉬기, 도망가기
- 클릭에 따른 화남 반응
- 커서 감지와 사냥 시퀀스
- 랜덤 춤
- 화면 경계 안쪽으로 위치 제한
- 실행용 최적화 스프라이트

## 실행 방법

```powershell
npm install
npm start
```
